# Classes

`Classes` 目录按 `NEChatUIKit/Classes` 对齐：

- `Common`
- `Base`
- `Chat`
- `ChatConfig`
- `ChatRouter`
- `Extension`
- `FunUI`
- `Markdown`
- `NormalUI`
- `Preview`
- `Protocol`

SwiftUI 专属能力放在对应业务目录内，例如 `Base/State`、`Base/Environment`、`Chat/Input`、`Chat/Operation`、`Chat/Location`。业务 UI 全部用 SwiftUI 重建。
